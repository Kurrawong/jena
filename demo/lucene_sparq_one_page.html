Jena SHACL luc:* One-Page Reference

Current API surface for SHACL-mode search. This page reflects the fixed-position signatures on main: explicit indexSelector, explicit fieldSpec, no ?match on luc:query, and field IRIs for all public field references.

luc:query

(?hit ?entity ?score ?totalHits)
  luc:query (indexSelector fieldSpec queryString cqlFilter sortSpec limit)

Use "null" for an unused cqlFilter or sortSpec.

luc:match

(?hit ?field ?value ?snippet) luc:match ()

Per-hit match detail lives here. This is the only match-detail API.

luc:facet

(?field ?value ?low ?high ?count)
  luc:facet (indexSelector fieldSpec queryString facetFields cqlFilter maxValues minCount)

The active supported subject form is the 5-slot form above.

Argument Rules

ConceptRule
indexSelectorString literal. Usually "default", but can also be a configured text:indexId or index resource IRI.
fieldSpecEither "default" or a JSON array of field IRIs.
Field referencesAlways field IRIs in fieldSpec, CQL property, sort specs, and facet arrays.
Graph filteringTarget model uses reserved synthetic field urn:jena:lucene:field#sourceGraph, not a dedicated ?graph slot.
ArityNo heuristic parsing. luc:query takes exactly 6 object args. luc:facet takes exactly 7 object args.
HighlightReserved for later. Not part of the active supported luc:query signature yet.

Examples

PREFIX luc: <urn:jena:lucene:index#>

SELECT ?entity ?score WHERE {
  (?hit ?entity ?score)
    luc:query ("default" "default" "learning" "null" "null" 20) .
}
PREFIX luc: <urn:jena:lucene:index#>

SELECT ?entity ?score WHERE {
  (?hit ?entity ?score)
    luc:query (
      "default"
      '["urn:jena:lucene:field#title"]'
      "copper"
      "null"
      '{"field":"urn:jena:lucene:field#year","order":"desc"}'
      10
    ) .
}
PREFIX luc: <urn:jena:lucene:index#>

SELECT ?entity ?field ?value WHERE {
  (?hit ?entity ?score)
    luc:query ("default" '["urn:jena:lucene:field#title"]' "copper" "null" "null" 10) .
  (?hit ?field ?value) luc:match () .
}
PREFIX luc: <urn:jena:lucene:index#>

SELECT ?field ?value ?low ?high ?count WHERE {
  (?field ?value ?low ?high ?count)
    luc:facet (
      "default"
      "default"
      "*"
      '["urn:jena:lucene:field#state", {"field":"urn:jena:lucene:field#year","ranges":[null,2000,2010,2020,null]}]'
      "null"
      20
      0
    ) .
}

Sort Syntax

Sort specs are JSON and use field IRIs in the public API.

{"field":"urn:jena:lucene:field#year","order":"desc"}
[
  {"field":"urn:jena:lucene:field#year","order":"desc"},
  {"field":"urn:jena:lucene:field#title"}
]

Graph Filtering

Target model: graph restriction is a normal CQL filter on a reserved synthetic field, not a special result binding. 

{"op":"=","args":[{"property":"urn:jena:lucene:field#sourceGraph"},"http://example.org/graph/A"]}
Shared execution is keyed by resolved index identity, field spec, query string, CQL filter, and sort spec. Matching luc:query, luc:facet, and luc:match calls reuse one Lucene search.
